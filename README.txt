РАЗМЕЩЕНИЕ СТРАНИЦЫ kompanpavel.com/rgb
=========================================

Что в архиве:
  rgb/
    index.html        — сама страница (всё в одном файле: стили, скрипты)
    assets/covers/    — 38 обложек изданий (оптимизированы для веба)
    assets/kompan-portrait.jpg — портрет Павла Компана в блоке цитаты

Как разместить (хостинг Beget):
  1. Зайти в панель Beget → Файловый менеджер (или подключиться по FTP).
  2. Открыть корневую папку сайта kompanpavel.com
     (обычно это kompanpavel.com/public_html).
  3. Загрузить папку rgb из архива целиком в корень сайта.
  4. Проверить: страница откроется по адресу https://kompanpavel.com/rgb/

Никаких настроек, баз данных или установки не требуется —
страница статическая и работает сразу после копирования файлов.

Библиотечные шифры:
  По решению заказчика шифры с сайта убраны. Заказ издания описан
  через поиск по названию в электронном каталоге search.rsl.ru.
  Если появятся реальные шифры РГБ, их можно вернуть — вёрстка для
  них в файле сохранена.

Шрифты подгружаются с Google Fonts — как и на основном сайте.
