# Лендинг «Коллекция fashion-изданий в РГБ» — kompanpavel.com/rgb

Одностраничный статический лендинг: каталог из 36 редких fashion-изданий,
переданных проектом KOMPAN PAVEL в фонды Российской государственной библиотеки.

**Стек:** чистый HTML/CSS/JS, без зависимостей и сборки. Шрифт Montserrat (Google Fonts).
Дизайн — в стилистике основного сайта kompanpavel.com: чёрный минимализм, золотой акцент.

## Структура

```
rgb/                  — готовая страница (заливается на хостинг как есть)
  index.html          — вся страница: разметка, стили, скрипты
  assets/covers/      — 36 обложек (оптимизированы, ≤700px)
build/
  gen.py              — генератор index.html из Excel-таблицы заказчика
  template.html       — шаблон страницы (токены __CARDS__, __TOTAL__ и т.д.)
README.txt            — инструкция по размещению для админа хостинга
```

## Секции страницы

Hero (лента обложек) → О проекте → Цитата П. Компана → 9 экспертов →
Каталог с фильтрами (Книги/Журналы, по эксперту, поиск по названию/шифру,
копирование шифра по клику) → «Три шага до архива» → футер.

Адаптив: десктоп / планшет / мобильный (375px+).

## ⚠️ Временные шифры

Библиотечные номера **ЕБШ10877–ЕБШ10912 — плейсхолдеры** (реальных шифров РГБ
ещё нет у заказчика). Задаются в `build/gen.py` (`code = f"ЕБШ{10876 + idx}"`).

## Пересборка

Если заказчик обновит таблицу (`Книги и журналы -2.xlsx` — в корне, в репо не хранится):

```bash
pip install openpyxl
python3 build/gen.py       # перегенерирует rgb/index.html
```

Обложки извлекаются из xlsx отдельно (см. историю проекта) и лежат в `rgb/assets/covers/`.

(`public_html`). Настроек не требуется. Подробнее — `README.txt`.
